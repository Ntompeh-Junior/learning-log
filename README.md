# Learning Log

Daily notes for topics I'm learning — AI evaluation, cybersecurity / GRC, writing, and tools.

**How to add today's note (2 minutes):**

1. Copy [`TEMPLATE.md`](TEMPLATE.md)
2. Save it as `notes/YYYY-MM-DD.md` (example: `notes/2026-09-19.md`)
3. Fill in What I learned / Practiced / Questions
4. Commit and push:

```bash
git add notes/
git commit -m "Add learning note for YYYY-MM-DD"
git push
```

Or in Cursor / VS Code: edit the file → Source Control → Commit → Sync.

GitHub will open a **reminder issue every day** (Accra time) so you don't forget. Close the issue after you push that day's note.
